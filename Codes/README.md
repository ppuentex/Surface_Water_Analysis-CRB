This folder contains all the code necessary to run the analysis of this project as well as instructions on how to download the data from the source and pre-processing steps to handle the data. 

## Contents 
 - `analysis.ipynb` &rarr; Jupyter notebook that produces all the .csv files in the `Data/analysis-data/` folder. 
 - `pre-processing.ipynb` &rarr; Jupyter notebook that walks you through the steps on how to download the data from the source, mosaic raster images, crop a raster file based on a shapefile, and calculate the mode for multiple raster files. 
 - `utils/` &rarr; folder containing classes and functions to run the analysis, these do not need to be modified.
